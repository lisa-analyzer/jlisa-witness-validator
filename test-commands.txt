Test commands for jLISA Witness Validator
==========================================

Run these from the repository root. They expect the SV_BENCHMARKS environment
variable to point to a local checkout of the SV-COMP benchmark repository
(https://gitlab.com/sosy-lab/benchmarking/sv-benchmarks) — specifically, the
directory that contains the `java/` folder.

    export SV_BENCHMARKS=/path/to/sv-benchmarks

Build the validator first:

    ./gradlew installDist


--- double2long (jdart-regression) ---
Violation path: Verifier.nondetDouble() = 1000.0 -> foo() else-branch -> l = 100L -> assert 100 < 100 fails

    python3 validator.py \
        --witness double2long-violation.graphml \
        --extra-sources "$SV_BENCHMARKS/java/common" \
        "$SV_BENCHMARKS/java/jdart-regression/double2long"


--- Ackermann01 (jayhorn-recursive) ---
Violation path: nondetInt()=0 (m), nondetInt()=0 (n) -> ack(0,0)=1 -> result>=0 -> assert false fires

    python3 validator.py \
        --witness ackermann01-violation.graphml \
        --extra-sources "$SV_BENCHMARKS/java/common" \
        "$SV_BENCHMARKS/java/jayhorn-recursive/Ackermann01"


Add --verbose to either command for the full JDI trace on stderr.
